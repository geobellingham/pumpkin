---
name: summarise-a-document
description: Summarise a long document, PDF, article or meeting notes the user gives or names. Use when they ask for a summary, the key points, a TL;DR or what a document says about something.
---

1. Find the document: an attachment in the chat, a file in the user's files (search with files_search) or a web page (read it). If several fit, ask which one.
2. Read all of it before writing. For a long document, go section by section and keep notes.
3. Write the summary:
   - One sentence saying what the document is (type, author or source, date when known).
   - The five to ten most important points, as short bullets, in the document's own order.
   - Numbers, dates, names and decisions exactly as written.
   - Anything the reader has to act on (deadlines, obligations, open questions) in its own short list.
4. When the user asked something specific, answer that first and quote the passage it comes from, with the page or section.
5. Never add facts that are not in the document. When something is unclear in the document, say so.
