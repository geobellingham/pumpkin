---
name: write-a-report
description: Research a topic and write a clear report with sources, saved as a file. Use when the user asks for a report, a write-up, a briefing or an overview they want to keep.
---

1. Work out what the report is for and who reads it. If that is unclear, make a sensible guess and say it in one line at the top.
2. Search the web for current information. Open and read at least three sources before relying on them. Prefer primary sources (official sites, papers, documentation) over blog summaries.
3. Write the report in Markdown:
   - A title and a two or three sentence summary that answers the main question.
   - Sections with short headings, in the order the reader needs them.
   - Numbers with their source and date. Say when sources disagree.
   - A short "What to do next" section when the report leads to a decision.
   - A "Sources" list at the end with the title and URL of every page you used.
4. Keep sentences short and plain. No filler, no "in conclusion".
5. Save it with files_save (a .md file, or .docx when the user wants Word) and tell the user the file name.
